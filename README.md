## 🧩 Engineering Principles

I try to keep architecture decisions grounded in the actual problem.

**Business requirements → Cost → Complexity → Performance → Security → Reliability → Scalability → Maintainability → Speed**

I prefer:

- Simple before complex
- Measured performance before optimization
- Clear boundaries before distributed architecture
- Reliable workflows before AI demos
- Explicit trade-offs before fashionable technology
- Production readiness before unnecessary abstraction

> **AI should solve real problems, not just demonstrate AI. A demo that works once is a demo; a system that works every Tuesday afternoon is a product.**
